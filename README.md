# DigitalKidney · 数字肾脏

Website: https://sunyq2022.github.io/DigitalKidney/

Research companion for *Background-constrained calibration for simulation-validated renal physiological inversion*. The site presents an established renal two-compartment forward model, background calibration, fixed-budget inverse comparisons and complementary acquired-image signal reconstruction. No journal acceptance or clinical injury localization is claimed.

## Interactive explorer

Open `index.html` directly or serve this directory with any static HTTP server. The browser runs the exact zero-order-hold recurrence from the research kernel, using a standard Parker arterial input, illustrative baseline parameters and the paper's q=0.20 calibration transformation. The point cloud is a procedural schematic, not acquired patient geometry. It performs no trained-network inference. The diffuse example preserves effective physical parameters in the revised baseline; zero corrected severity is not evidence of recovery.

## Reproducibility and evidence

`study-data.json` contains selected aggregate results, primary source links and source SHA256 fingerprints. `results.csv` reports participant-level aggregate comparisons with intervals. Source references retain publication/preprint status. The manuscript and full scientific computation package remain separate from this website; no acquired images, measured curve arrays, patient point fields, credentials or local paths are distributed as datasets here. Four article figures are included with their evidence scope stated in captions; the BLADE figure contains a cited public-data image example.

The original anatomy split comprises 30 training, 12 validation and 18 test participants. Reviewer sensitivity experiments reuse previously accessed anatomy, not an independent new cohort. Real acquired-image confirmation comprises 12 healthy participants. Separate source cohorts are not paired. Reference interval diagnostics do not establish clinical coverage.

Run `node test_physics.cjs` to compare browser concentration and MR enhancement against five Python-kernel fixtures, check calibration-product invariance and demonstrate diffuse erasure. The maximum accepted absolute kernel discrepancy is 1e-10. These tests validate the implemented equations, not clinical physiology.
