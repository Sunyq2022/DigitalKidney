# DigitalKidney

Website: https://sunyq2022.github.io/DigitalKidney/

English research companion for quality-guided renal physiological inversion, with simulation on public anatomy and complementary acquired MRI/reference checks. Updated 3 October 2026. No journal acceptance or clinical injury localization is claimed.

## Interactive explorer

Open `index.html` directly or serve this directory with any static HTTP server. The browser runs the exact zero-order-hold recurrence from the research kernel, using a standard Parker arterial input, illustrative baseline parameters and the paper's q=0.20 calibration transformation. The point cloud is a procedural schematic, not acquired patient geometry. It performs no trained-network inference. The diffuse example preserves effective physical parameters in the revised baseline; zero corrected severity is not evidence of recovery.

## Reproducibility and evidence

`study-data.json` contains aggregate results, the 50 manuscript sources and source SHA256 fingerprints. `results.csv` distinguishes participant and examination units in its scope column. Source references retain publication/preprint status. The manuscript and full scientific computation package remain separate from this website; no acquired images, measured curve arrays, patient point fields, credentials or local paths are distributed as datasets here. Seven figures are included with their evidence scope stated in captions; the BLADE figure contains a cited public-data image example.

The original anatomy split comprises 30 training, 12 validation and 18 test participants. Reviewer sensitivity experiments reuse previously accessed anatomy. New untuned replication retains 513 MRI examinations, without verified participant independence, from TotalSegmentator MRI v3.0.0. Acquired-image confirmation comprises 12 healthy BLADE participants; isotope split-function evaluation reuses the 60 reserved KRUK participants without changing their fits. Separate source cohorts are not paired. Reference interval diagnostics do not establish clinical coverage.

Run `node test_physics.cjs` to compare browser concentration and MR enhancement against five Python-kernel fixtures, check calibration-product invariance and demonstrate diffuse erasure. The maximum accepted absolute kernel discrepancy is 1e-10. These tests validate the implemented equations, not clinical physiology.
